# Auto Launcher

Автомобильный Android-лаунчер для головного устройства YT5760B (Android 9 / API 28, экран 1024×600, ARM 32-bit).

## Сборка
Проект собирается в GitHub Actions. После успешной сборки APK появится в Actions → последний запуск → Artifacts.

## Текущий этап 0.1.0
- Горизонтальный тёмный интерфейс.
- GPS-скорость через системный LocationManager (после выдачи разрешения).
- Левая панель ярлыков и список установленных приложений.
- Отдельная панель OBD2 с пустыми значениями до реализации протокола.
- Временная область карты; это ещё не встроенный Яндекс Навигатор.
- Радио и музыка пока являются макетом.

OBD2/K-Line, расчёт среднего расхода, интеграция Яндекс Навигатора, штатного FM-тюнера и управление медиаплеерами будут добавляться отдельными этапами после проверки совместимости магнитолы.
